How to install

  1. Download the .apk file to your Android device using the button above.
  2. Open the downloaded file. If prompted, allow your browser to install unknown apps.
  3. Follow the on-screen prompts to complete installation.
  4. Open the app and follow the setup steps to enable content blocking.

This app is distributed directly as an .apk and is not listed on the Google Play Store, so Android will warn you before installing it. This is expected for apps installed outside the Play Store.
