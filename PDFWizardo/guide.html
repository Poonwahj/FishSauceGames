PDFWizardo guide

PDFWizardo fills in a Word template, does the calculations for you, and saves a finished PDF. This guide covers using it day to day and setting up your own templates.

Using PDFWizardo

  1. Sign in with your work Microsoft 365 account and pick the OneDrive folder that holds your templates (Word .docx files).
  2. Choose a template. PDFWizardo reads it and builds a form from its tags.
  3. Type who the copy is for at the top of the form, then fill in the blanks. Calculated values update as you type.
  4. Create copy. The finished PDF (and, if you tick the box, a Word copy) is saved to a Generated folder inside your templates folder.

Not signed in? You can still open a .docx from this computer to try a template. You get the filled-in Word file as a download.

Step 1: Put tags in the document

Type @ and a name wherever a value should appear. Use the same tag as often as you like: every copy of it gets the same value. Tags in headers and footers work too.

  • @ClientName: letters, numbers and _ only, with no spaces.
  • @clientname is the same field. Capital letters don't matter.
  • Email addresses such as name@example.com are left alone.

That's all a simple document needs. Each tag becomes a box on the form, labelled from its name, so @ClientName asks for "Client Name".

Step 2: Describe the fields and add calculations (optional)

On the last page, type a line that says PDFWizardo Fields, then one field per line. This section is removed from every copy, so it never reaches the client.

  • @Name : question is something you fill in. The question is shown on the form.
  • @Name = formula is calculated for you and never asked.
  • Options go in [square brackets] at the end of the line, separated by commas.
  • Lines that don't start with @ are ignored, so you can leave notes for yourself.

A complete example

In the document

This agreement begins on @StartDate and ends on @EndDate.
@ClientName agrees to pay @MonthlyFee per month for @Months months.

Net total: @NetTotal
Tax at @TaxRate: @Tax
Total due: @GrandTotal (@TotalInWords)
Deposit due on signing: @Deposit

On the last page, after a page break

PDFWizardo Fields
@ClientName   : Client's full legal name
@StartDate    : Start date [date, default today]
@Months       : Length in months [number, default 12]
@MonthlyFee   : Monthly fee before tax [currency]
@Discount     : One-time discount [currency, optional]
@TaxRate      : Sales tax rate [percent, default 13]

Everything below is calculated.
@NetTotal     = @MonthlyFee * @Months - @Discount [currency]
@Tax          = round(@NetTotal * @TaxRate, 2) [currency]
@GrandTotal   = @NetTotal + @Tax [currency]
@Deposit      = max(500, round(@GrandTotal * 20%, 2)) [currency]
@EndDate      = addMonths(@StartDate, @Months) - 1
@TotalInWords = moneyWords(@GrandTotal)

The form asks for the six fields marked with : and works out the rest as you type. A fee of $2,500 for 12 months at 13% tax gives a total due of $33,900.00 and a deposit of $6,780.00. The copy says "Total due: $33,900.00 (Thirty-Three Thousand Nine Hundred and 00/100)".

Good to know

  • Start PDFWizardo Fields on a new page (Ctrl+Enter in Word). The page break before it is removed too.
  • Fields can be listed in any order, and formulas can use other formulas.
  • Word's autocorrect is fine. Curly quotes, long dashes and × are understood.
  • If a line has a mistake, PDFWizardo says what's wrong at the top of the form.
  • The template itself is never changed. Copies go into a Generated folder inside the templates folder. The file name is filled in for you from who the copy is for and today's date, and you can change it before saving.
  • Keep this guide out of the templates folder, or PDFWizardo will list it as a template.
